## 概述

- 文档官网：[SpringAI—RAG](https://java2ai.com/integration/rag/retrieval-augmented-generation)

### 概念

### Advisors

`Spring AI` 使用 `Advisor` API 为常见的 RAG 流程提供了开箱即用高度化定制的支持，分别提供了 `QuestionAnswerAdvisor` 和 `VectorStoreChatMemoryAdvisor` 组件

- `QuestionAnswerAdvisor` 是一个开箱即用的轻量级 RAG 组件，专注于快速完成“向量检索与上下文拼接”的基础问答链路；

- `RetrievalAugmentationAdvisor` 是一个高度模块化的 RAG 编排引擎，支持在检索前后进行查询重写、结果重排等高级定制，以应对复杂的检索增强生成场景

#### QuestionAnswerAdvisor

引入依赖：

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-advisors-vector-store</artifactId>
</dependency>
```

向 `ChatClient` 提供 `QuestionAnswerAdvisor` 的实例来执行 RAG

```java
var qaAdvisor = QuestionAnswerAdvisor.builder(vectorStore)
    .searchRequest(SearchRequest.builder()
                   .similarityThreshold(0.8)
                   .topK(5)
                   .build())
    .build();

dashScopeChatClient.prompt()
    .advisors(qaAdvisor)
    .user(question)
    .call()
    .content();
```

#### RetrievalAugmentationAdvisor

引入依赖

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-rag</artifactId>
</dependency>
```

### VectorStoreDocumentRetriever

`VectorStoreDocumentRetriever` 是 RAG 流程中**检索阶段的具体执行器**。它实现了 `DocumentRetriever` 接口，专门负责基于向量数据库进行高效的语义相似性检索

核心作用：

1. 将用户的查询文本转换为向量
2. 在底层的向量数据库中计算查询向量与文档向量的相似度
3. 根据设定的过滤条件和阈值，筛选并返回最相关的文档片段列表

关键参数：

- **vectorStore**：指定要在哪个向量数据库中进行检索
- **similarityThreshold**：相似度阈值，只有相似度达到或超过该阈值的文档才会被召回
- **topK**：返回数量，限制最多返回多少个最相关的文档
- **filterExpression**：元数据过滤，支持根据文档的元数据进行条件过滤

#### RAG 配置类

- 配置向量模型、向量存储

```java
@Configuration
public class RagConfig {

    @Bean
    public DashScopeApi ragDashScopeApi() {
        return DashScopeApi.builder()
                .apiKey("密钥")
                .build();
    }

    @Bean
    public EmbeddingModel dashScopeEmbeddingModel(DashScopeApi ragDashScopeApi) {
        return DashScopeEmbeddingModel.builder()
                .dashScopeApi(ragDashScopeApi)
                .defaultOptions(DashScopeEmbeddingOptions.builder()
                        .model("text-embedding-v3")
                        .build())
                .build();
    }

    @Bean
    public MilvusServiceClient milvusServiceClient() {
        return new MilvusServiceClient(ConnectParam.newBuilder()
                .withAuthorization("root", "Milvus")
                .withUri("http://IP地址:19530")
                .build());
    }

    @Bean
    public VectorStore milvusVectorStore(
            MilvusServiceClient milvusServiceClient,
            @Qualifier("dashScopeEmbeddingModel") EmbeddingModel embeddingModel) {
        return MilvusVectorStore.builder(milvusServiceClient, embeddingModel)
                .collectionName("rag_demo_collection")
                .databaseName("default")
                .indexType(IndexType.IVF_FLAT)
                .metricType(MetricType.COSINE)
                .batchingStrategy(new TokenCountBatchingStrategy())
                .initializeSchema(true)
                .build();
    }
}

```

#### 自动 RAG

```java
@Service
public class RagService {

    private final VectorStore vectorStore;
    private final ChatClient dashScopeChatClient;

    public RagService(
        VectorStore vectorStore,
        @Qualifier("dashScopeChatClient") ChatClient dashScopeChatClient) {
        this.vectorStore = vectorStore;
        this.dashScopeChatClient = dashScopeChatClient;
    }

    /**
     * RAG 问答 - 使用 QuestionAnswerAdvisor
     */
    public String rag(String question, int topK) {
        var qaAdvisor = QuestionAnswerAdvisor.builder(vectorStore)
            .searchRequest(SearchRequest.builder()
                           .similarityThreshold(0.8)
                           .topK(topK)
                           .build())
            .build();

        return dashScopeChatClient.prompt()
            .advisors(qaAdvisor)
            .user(question)
            .call()
            .content();
    }

    /**
     * 添加文档到向量数据库
     */
    public void addDocuments(List<String> documents) {
        List<Document> docs = documents.stream()
            .map(Document::new)
            .toList();
        vectorStore.add(docs);
    }

    /**
     * 根据 ID 删除文档
     */
    public void deleteDocuments(List<String> documentIds) {
        vectorStore.delete(documentIds);
    }

    /**
     * 相似度搜索
     */
    public List<Document> similaritySearch(String query, int topK) {
        return vectorStore.similaritySearch(
            SearchRequest.builder()
            .query(query)
            .topK(topK)
            .build()
        );
    }

}
```

#### 接口

```java
@RestController
@RequestMapping("/rag")
public class RagController {

    private final RagService ragService;

    public RagController(RagService ragService) {
        this.ragService = ragService;
    }

    /**
     * 添加文档到向量数据库
     */
    @PostMapping("/documents")
    public String addDocuments(@RequestBody List<String> documents) {
        ragService.addDocuments(documents);
        return "成功添加 " + documents.size() + " 个文档";
    }

    /**
     * 删除文档
     */
    @DeleteMapping("/documents")
    public String deleteDocuments(@RequestBody List<String> documentIds) {
        ragService.deleteDocuments(documentIds);
        return "成功删除 " + documentIds.size() + " 个文档";
    }

    /**
     * 相似度搜索
     */
    @GetMapping("/search")
    public List<Document> search(
            @RequestParam String query,
            @RequestParam(defaultValue = "3") int topK) {
        return ragService.similaritySearch(query, topK);
    }

    /**
     * RAG 问答
     */
    @GetMapping("/chat")
    public String ragChat(
            @RequestParam String question,
            @RequestParam(defaultValue = "3") int topK) {
        return ragService.rag(question, topK);
    }
}
```

```java
public String ragAdvanced(String question, int topK, ChatClient.Builder chatClientBuilder) {
    var retrievalAugmentationAdvisor = RetrievalAugmentationAdvisor.builder()
        .queryTransformers(RewriteQueryTransformer.builder()					// 重写查询器
                           .chatClientBuilder(chatClientBuilder.build().mutate())
                           .build())
        .documentRetriever(VectorStoreDocumentRetriever.builder()				// 文档检索器
                           .similarityThreshold(0.5)
                           .topK(topK)
                           .vectorStore(vectorStore)
                           .build())
        .build();

    return chatClientBuilder.build().prompt()
        .advisors(retrievalAugmentationAdvisor)
        .user(question)
        .call()
        .content();
}
```

#### 手动 RAG

```java
public String ragManual(String question, int topK) {
    // 1. 检索相关文档
    List<Document> documents = similaritySearch(question, topK);

    // 2. 构建上下文
    StringBuilder context = new StringBuilder();
    for (Document doc : documents) {
        context.append(doc.getText()).append("\n\n");
    }

    // 3. 构建提示词
    String prompt = """
        你是一个问答助手。请根据以下上下文来回答用户的问题。
        如果上下文中没有相关信息，请如实告知用户。

        上下文：
        %s

        问题：%s

        请基于上下文回答问题：
        """.formatted(context.toString(), question);

        // 4. 调用模型
        return dashScopeChatClient.prompt()
        .user(prompt)
        .call()
        .content();
}
```
