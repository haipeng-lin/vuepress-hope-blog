## 前言

Elasticsearch 在 8.x 版本后全面增强了对向量检索的支持，提供了包括 KNN（K-Nearest Neighbors）、ANN（Approximate Nearest Neighbors）算法以及高效的 RRF（Reciprocal Rank Fusion，倒数排名融合）重排序算法。这使得开发者能够在一个系统内同时利用 BM25 算法的精确匹配能力与向量空间模型的语义理解能力，大幅提升搜索系统的召回率与准确率。

ok，那为什么要这种融合检索呢，有什么好处？

我们通过一个具体的**电商购物场景**来生动理解为什么要进行这种融合：

假设用户在一个庞大的电商平台搜索： **“苹果”**

**场景一：仅靠关键词检索**

如果你只用关键词检索，系统会机械地在数据库中查找包含“苹果”这两个字的所有商品。

- **结果：** 搜索结果里会同时出现 **“新鲜的陕西红富士苹果”** （水果）和 **“iPhone 15 Pro Max”** （手机）。

- **痛点：** 系统无法区分你到底想买吃的还是用的。如果你的查询词稍微模糊一点，或者商品标题里用了“苹果手机”但没写“iPhone”，系统可能就傻眼了。它虽然精准匹配了字面，但缺乏对“意图”的理解。

**场景二：仅靠向量检索**

如果你只用向量检索，系统会将“苹果”转化为向量，去语义空间里找相似的东西。

- **结果：** 系统可能会根据语义联想，给你推荐 **“梨子”、“香蕉”** （因为都是水果），或者 **“华为”、“小米”** （因为都是手机品牌）。

- **痛点：** 虽然语义理解很强，但向量检索往往会丢失“精确性”。如果你心里非常明确就是要买“iPhone 15”这一款特定型号，向量检索可能会因为觉得“华为”和“苹果”在语义上都是“高端手机”，就把华为也推给你，导致**精确匹配能力的缺失**。

**场景三：融合检索**

当我们引入 Elasticsearch 的混合检索时，情况就变了：

- **关键词检索**：负责守住底线，确保结果里必须包含用户输入的核心词汇，或者严格符合某些过滤条件（比如品牌必须是 Apple）。

- **向量检索**：负责拓宽视野，理解用户输入“手感好的手机”时，能联想到“iPhone”或“轻薄机身”，即使商品标题里没有“手感好”这三个字。

- **RRF（倒数排名融合）**：这是最终的“裁判”。它不会简单地把两份名单拼在一起，而是通过 RRF 算法综合计算两者的排名权重。

## 环境准备

### 安装 ElasticSearch

1. 创建宿主机并配置权限

```shell
# 创建 ES 和 Kibana 的数据、配置、日志、插件目录
mkdir -p /home/docker/es/{data,config,logs,plugins}
mkdir -p /home/docker/kibana/{data,config,logs,plugins}

# 赋予目录权限（UID 1000）
chown -R 1000:1000 /home/docker/es
chown -R 1000:1000 /home/docker/kibana
```

2. 创建专用 Docker 网络

```shell
docker network create es-net
```

3. 启动临时 ES 容器并复制核心文件

```shell
# 启动一个临时的 ES 容器（单节点模式）
docker run -d \
  --name temp_es \
  -e "discovery.type=single-node" \
  -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" \
  docker.elastic.co/elasticsearch/elasticsearch:8.17.2

# 将容器内的核心文件复制到宿主机
docker cp temp_es:/usr/share/elasticsearch/config/. /home/docker/es/config/
docker cp temp_es:/usr/share/elasticsearch/plugins/. /home/docker/es/plugins/
docker cp temp_es:/usr/share/elasticsearch/data/. /home/docker/es/data/

# 删除临时容器
docker stop temp_es && docker rm temp_es
```

4. 正式挂载启动 ES 容器

```shell
docker run -d \
  --name elasticsearch \
  --network es-net \
  -p 9200:9200 \
  -p 9300:9300 \
  -e "discovery.type=single-node" \
  -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" \
  -v /home/docker/es/data:/usr/share/elasticsearch/data \
  -v /home/docker/es/config:/usr/share/elasticsearch/config \
  -v /home/docker/es/plugins:/usr/share/elasticsearch/plugins \
  -v /home/docker/es/logs:/usr/share/elasticsearch/logs \
  docker.elastic.co/elasticsearch/elasticsearch:8.17.2
```

5. 观察是否正常运行

```shell
docker ps
```

6. 设置 elastic 用户的密码，执行以下命令，系统会提示您输入两次新密码：

```shell
docker exec -it elasticsearch /usr/share/elasticsearch/bin/elasticsearch-reset-password -u elastic -i
```

7. 测试，注意从 ES 8.0 开始，默认为 https，输入用户名密码，出现版本信息则启动成功

```shell
https://IP:9200/
```

```java
    ElasticsearchVectorStoreOptions options = new ElasticsearchVectorStoreOptions();

    return ElasticsearchVectorStore.builder(restClient, dashScopeEmbeddingModel)
        .options(options)
        .initializeSchema(true)
        .batchingStrategy(new TokenCountBatchingStrategy())
        .build();
}
```

```java
public List<Document> chunkBySemantic(String content, int targetSize, Map<String, Object> metadata) {
    List<Document> chunks = new ArrayList<>();

    if (content == null || content.isEmpty()) {
        return chunks;
    }

    // 第一步：按段落分割
    List<String> paragraphs = splitIntoParagraphs(content);

    // 第二步：每个段落内按句子分割
    List<String> sentences = new ArrayList<>();
    for (String paragraph : paragraphs) {
        if (!paragraph.trim().isEmpty()) {
            List<String> paragraphSentences = splitIntoSentences(paragraph);
            sentences.addAll(paragraphSentences);
        }
    }

    if (sentences.isEmpty()) {
        // 如果没有句子，把整个内容作为一个切片
        chunks.add(createChunk(content, metadata, 0));
        return chunks;
    }

    // 第三步：按语义单元分组
    List<List<String>> semanticChunks = groupIntoSemanticChunks(sentences, targetSize);

    // 第四步：创建 Document
    for (int i = 0; i < semanticChunks.size(); i++) {
        List<String> chunkSentences = semanticChunks.get(i);
        String chunkText = String.join("", chunkSentences);
        Map<String, Object> chunkMetadata = new java.util.HashMap<>(metadata);
        chunkMetadata.put("chunkIndex", i);
        chunkMetadata.put("totalChunks", semanticChunks.size());
        chunkMetadata.put("sentenceCount", chunkSentences.size());
        chunkMetadata.put("charCount", chunkText.length());
        chunks.add(new Document(chunkText, chunkMetadata));
    }

    logger.info("语义切片完成，共 {} 个切片", chunks.size());
    for (Document chunk : chunks) {
        logger.info("  切片 {}: {} 字符, {} 句子",
                    chunk.getMetadata().get("chunkIndex"),
                    chunk.getMetadata().get("charCount"),
                    chunk.getMetadata().get("sentenceCount"));
    }

    return chunks;
}
```

#### 混合检索

```java
public List<SearchResult> hybridSearch(String query,
                                       int topK,
                                       double bm25Weight,
                                       double knnWeight,
                                       double threshold) {
    try {
        float[] queryVector = generateEmbedding(query);
        List<Float> queryVectorList = new ArrayList<>();
        for (float v : queryVector) {
            queryVectorList.add(v);
        }

        // 1. BM25 检索
        SearchResponse<Map> bm25Response = elasticsearchClient.search(s -> s
                                                                      .index(indexName)
                                                                      .size(topK * 2)
                                                                      .query(q -> q
                                                                             .bool(b -> b
                                                                                   .should(sh -> sh.match(m -> m
                                                                                                          .field("content")
                                                                                                          .query(query)
                                                                                                          .boost(2.0f)
                                                                                                         ))
                                                                                   .should(sh -> sh.match(m -> m
                                                                                                          .field("tokens")
                                                                                                          .query(query)
                                                                                                          .boost(1.5f)
                                                                                                         ))
                                                                                   .should(sh -> sh.match(m -> m
                                                                                                          .field("contentKeyword")
                                                                                                          .query(query)
                                                                                                          .boost(1.0f)
                                                                                                         ))
                                                                                  )
                                                                            )
                                                                      , Map.class);

        // 2. KNN 向量检索
        SearchResponse<Map> knnResponse = elasticsearchClient.search(s -> s
                                                                     .index(indexName)
                                                                     .size(topK * 2)
                                                                     .knn(k -> k
                                                                          .field("embedding")
                                                                          .queryVector(queryVectorList)
                                                                          .k(topK * 2)
                                                                          .numCandidates(topK * 4)
                                                                         )
                                                                     , Map.class);

        // 收集 BM25 结果
        Map<String, SearchResult> docMap = new LinkedHashMap<>();
        Map<String, Integer> bm25Ranks = new LinkedHashMap<>();
        int bm25Idx = 0;

        for (Hit<Map> hit : bm25Response.hits().hits()) {
            String id = hit.id();
            SearchResult result = buildResult(id, hit.source());
            if (result == null) continue;

            bm25Ranks.put(id, ++bm25Idx);
            result.setBm25Score(hit.score());
            result.setBm25Rank(bm25Idx);
            docMap.put(id, result);
        }

        // 收集 KNN 结果
        Map<String, Integer> knnRanks = new LinkedHashMap<>();
        int knnIdx = 0;

        for (Hit<Map> hit : knnResponse.hits().hits()) {
            String id = hit.id();
            knnRanks.put(id, ++knnIdx);

            if (!docMap.containsKey(id)) {
                SearchResult result = buildResult(id, hit.source());
                if (result != null) {
                    result.setKnnScore(hit.score());
                    result.setKnnRank(knnIdx);
                    docMap.put(id, result);
                }
            } else {
                docMap.get(id).setKnnScore(hit.score());
            }
        }

        // 应用层 RRF 融合
        List<SearchResult> results = applyRrf(
            new ArrayList<>(docMap.values()),
            bm25Ranks, knnRanks,
            bm25Weight, knnWeight);

        return results.stream()
            .filter(r -> r.getRrfScore() >= threshold)
            .limit(topK)
            .collect(Collectors.toList());

    } catch (Exception e) {
        logger.error("混合检索失败: {}", e.getMessage(), e);
        throw new RuntimeException("混合检索失败", e);
    }
}

/**
     * 应用层 RRF 融合
     */
private List<SearchResult> applyRrf(List<SearchResult> docs,
                                    Map<String, Integer> bm25Ranks,
                                    Map<String, Integer> knnRanks,
                                    double bm25Weight, double knnWeight) {
    Map<String, Double> rrfScores = new HashMap<>();

    for (SearchResult doc : docs) {
        String id = doc.getId();
        int bm25Rank = bm25Ranks.getOrDefault(id, Integer.MAX_VALUE);
        int knnRank = knnRanks.getOrDefault(id, Integer.MAX_VALUE);

        // 设置 BM25 和 KNN 排名
        doc.setBm25Rank(bm25Rank < Integer.MAX_VALUE ? bm25Rank : null);
        doc.setKnnRank(knnRank < Integer.MAX_VALUE ? knnRank : null);

        double totalWeight = bm25Weight + knnWeight;
        double normBm25 = bm25Weight / totalWeight;
        double normKnn = knnWeight / totalWeight;

        double score = 0.0;
        if (bm25Rank < Integer.MAX_VALUE && knnRank < Integer.MAX_VALUE) {
            score = normBm25 / (RRF_K + bm25Rank) + normKnn / (RRF_K + knnRank);
        } else if (bm25Rank < Integer.MAX_VALUE) {
            score = normBm25 / (RRF_K + bm25Rank);
        } else if (knnRank < Integer.MAX_VALUE) {
            score = normKnn / (RRF_K + knnRank);
        }

        rrfScores.put(id, score);
    }

    List<SearchResult> sorted = docs.stream()
        .sorted((a, b) -> Double.compare(
            rrfScores.getOrDefault(b.getId(), 0.0),
            rrfScores.getOrDefault(a.getId(), 0.0)))
        .collect(Collectors.toList());

    for (int i = 0; i < sorted.size(); i++) {
        SearchResult doc = sorted.get(i);
        doc.setRrfScore(rrfScores.get(doc.getId()));
        doc.setRrfRank(i + 1);
    }

    return sorted;
}
```
