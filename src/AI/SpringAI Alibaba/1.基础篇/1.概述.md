## 前言

官方文档：[SpringAI Alibaba](https://java2ai.com/)

### 与 SpringAI 对比

- Spring AI 是 Spring 官方社区主导的 Java 生态通用 AI 开发底座，核心目标是建立统一的 AI 编程模型，屏蔽不同厂商、不同模型的调用差异，让 Java 开发者无需关注底层接口细节，就能快速集成 AI 能力
- Spring AI Alibaba 是阿里巴巴与 Spring 官方联合开发、阿里主导维护的增强方案，完全基于 Spring AI 的底层抽象构建，不重复造轮子。它的核心价值是 “对接国内生态 + 补齐企业级能力”

| 对比维度       | Spring AI                                                          | Spring AI Alibaba                                                                                         |
| :------------- | :----------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------- |
| 归属主体       | Spring 官方社区                                                    | 阿里巴巴 + Spring 官方联合开发，阿里主导维护                                                              |
| 核心定位       | Java 生态通用 AI 开发底座                                          | 适配阿里云生态的企业级 AI 开发增强方案                                                                    |
| 核心目标       | 统一 AI 调用编程模型，降低跨厂商集成成本                           | 对接阿里云服务与国内大模型，支撑企业级复杂场景落地                                                        |
| 原生模型支持   | 海外主流模型                                                       | 阿里云千问等国内主流模型                                                                                  |
| **核心能力**   | 基础模型调用、文本向量化、函数调用、简单提示词模板、向量数据库集成 | 继承 Spring AI 所有基础能力 + 智能体编排（Graph 框架） + 可视化调试观测（Studio 模块） + 阿里系中间件集成 |
| 生态对接       | 通用跨厂商生态，无绑定云服务                                       | 深度绑定阿里云生态（百炼平台、Nacos、Higress AI 网关、OSS 等）                                            |
| **企业级特性** | 缺乏服务治理、流程编排、调试观测能力                               | 支持降级、熔断、限流、大规模部署、链路监控等生产级特性                                                    |

### 核心功能

- **强大的 Graph 智能体编排框架**：它结合了工作流（Workflow）与自动化代理（Autonomous Agent）的优势，专为多智能体（Multi-Agent）协作和复杂任务编排设计

  - **多模式编排**：内置 SequentialAgent、ParallelAgent、RoutingAgent、LoopAgent 等多种模式，支持条件分支、并行处理、循环流程控制
  - **状态管理与人工干预**：提供全局状态（OverallState）在节点间传递数据，支持流程快照与记忆持久化。同时支持在流程中设置中断，等待人类确认或修改状态值，以提高业务执行的可靠性
  - **A2A 通信**：支持 Agent-to-Agent 协议，实现多智能体之间的分布式协调与协作

- **完善的开发者工具链**

  - **Spring AI Alibaba Studio**：提供本地 Web UI 调试工具，支持模型交互效果调试、参数调整、工作流运行及知识库检索的可视化\*\*
  - **Project Initializer**：提供低代码可视化平台，支持拖拽式绘制工作流和配置 Chatbot，并可直接导出 Java 项目源码

- **基础 AI 原子能力**
  - 完全继承并扩展了 Spring AI 的基础能力，包括统一的 ChatClient 接口、RAG 检索增强、Function Calling 工具调用、Prompt 模板管理以及多模态支持

### 企业级特性

**1. 深度绑定阿里云生态**
Spring AI Alibaba 与国内主流大模型及云原生基础设施进行了原生对齐，彻底解决了国内网络访问海外模型不稳定的痛点：

- **百炼平台集成**：开箱即用通义千问全系模型，参数完全对齐；支持直接对接百炼平台的知识库和向量化服务
- **Nacos 服务治理**：实现提示词的集中存储、版本控制与动态热加载；支持基于语义的 MCP 服务发现与负载均衡
- **Higress AI 网关**：作为 AI 网关提供流量控制、Token 限流、熔断机制，支持 HTTP/Dubbo 服务零改造自动转为 MCP 服务，并集成 WAF 插件保障安全合规

**2. 生产级性能与稳定性保障**

- **企业级状态管理**：提供全局状态结合 KeyStrategy 隔离策略，天然支持多会话、多用户、多任务的状态隔离与记忆持久化
- **异步非阻塞执行**：支持异步节点声明，大幅提升高并发场景下的系统吞吐量
- **标准流式输出**：基于 Spring Reactor Flux 实现 SSE 流式响应，完美适配前端实时打字效果及长文本生成场景
- **全链路可观测性**：无缝集成 ARMS、Langfuse 等观测产品，提供 AI 应用级别的链路监控与评估能力

### 依赖管理

通过 BOM 统一版本，避免与 Spring AI、Spring Boot 冲突：

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.1.2.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
        <dependency>
            <groupId>org.springframework.ai</groupId>
            <artifactId>spring-ai-bom</artifactId>
            <version>1.1.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-extensions-bom</artifactId>
            <version>1.1.2.1</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
        </dependencyManagement>

    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-agent-framework</artifactId>
        </dependency>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
        </dependency>
    </dependencies>
```
