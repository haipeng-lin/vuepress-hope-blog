## OpenAI

### 自动配置

引入依赖：

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-model-openai</artifactId>
</dependency>
```

- 连接配置

| 属性                             | 描述         | 默认                   |
| -------------------------------- | ------------ | ---------------------- |
| spring.ai.openai.base-url        | URL          | https://api.openai.com |
| spring.ai.openai.api-key         | Key          |                        |
| spring.ai.openai.organization-id | 可选，组织Id |                        |
| spring.ai.openai.project-id      | 可选，项目Id |                        |

- 重试配置

| Property                                 | Description                                                  | Default |
| :--------------------------------------- | :----------------------------------------------------------- | :------ |
| spring.ai.retry.max-attempts             | 最大重试次数                                                 | 10      |
| spring.ai.retry.backoff.initial-interval | 指数退避策略的初始睡眠持续时间                               | 2 sec.  |
| spring.ai.retry.backoff.multiplier       | 退避间隔乘数                                                 | 5       |
| spring.ai.retry.backoff.max-interval     | 最大退避持续时间。                                           | 3 min.  |
| spring.ai.retry.on-client-errors         | 如果为 false，抛出 NonTransientAiException，并且不对 `4xx` 客户端错误代码尝试重 | false   |
| spring.ai.retry.exclude-on-http-codes    | 不应触发重试的 HTTP 状态代码列表（例如，抛出 NonTransientAiException） | empty   |
| spring.ai.retry.on-http-codes            | 应触发重试的 HTTP 状态代码列表（例如，抛出 TransientAiException） | empty   |

yml 示例：

```yml
spring:
  ai:
    openai:
      base-url: 地址
      api-key: 密钥
      chat:
        options:
          model: deepseek-v4-flash
```

接口：

```java
@RestController
@RequestMapping("/api/chat")
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    @GetMapping("/stream")
    public Flux<String> chatStream(@RequestParam(defaultValue = "你好") String message) {
        return chatClient.prompt(message).stream().content();
    }

}
```

### 手动配置

引入依赖：

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-openai</artifactId>
</dependency>
```

配置：

```java
@Configuration
public class OpenAiConfig {

    @Bean
    public OpenAiApi openAiApi() {
        return OpenAiApi.builder()
                .apiKey("密钥")
                .baseUrl("地址")
                .build();
    }

    @Bean
    @Qualifier("openAiChatModel")
    public OpenAiChatModel openAiChatModel(OpenAiApi openAiApi) {
        return OpenAiChatModel.builder()
                .openAiApi(openAiApi)
                .defaultOptions(OpenAiChatOptions.builder()
                        .model("deepseek-chat")
                        .temperature(0.7)
                        .maxTokens(1000)
                        .build())
                .build();
    }

    @Bean
    public ChatClient openAiChatClient(@Qualifier("openAiChatModel") OpenAiChatModel openAiChatModel) {
        return ChatClient.builder(openAiChatModel).build();
    }
}
```

测试接口：

```java
private final ChatClient chatClient;

public ChatController(ChatClient chatClient) {
    this.chatClient = chatClient;
}
```

## DashScope

### 自动配置

引入依赖：

```xml
<dependency>
    <groupId>com.alibaba.cloud.ai</groupId>
    <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
</dependency>
```

yml 配置：

```yml
spring:
  ai:
    dashscope:
      base-url: 地址
      api-key: 密钥
      chat:
        options:
          model: qwen-plus
```

测试接口：

```java
@RestController
@RequestMapping("/api/chat")
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    @GetMapping("/stream")
    public Flux<String> chatStream(@RequestParam(defaultValue = "你好") String message) {
        return chatClient.prompt(message).stream().content();
    }

}
```

### 手动配置

引入依赖：

```xml
<dependency>
    <groupId>com.alibaba.cloud.ai</groupId>
    <artifactId>spring-ai-alibaba-dashscope</artifactId>
</dependency>
```

配置：

```java
@Configuration
public class DashScopeConfig {

    @Bean
    public DashScopeApi dashScopeApi() {
        return DashScopeApi.builder()
                .apiKey("密钥")
                .build();
    }

    @Bean
    @Qualifier("dashScopeChatModel")
    public DashScopeChatModel dashScopeChatModel(DashScopeApi dashScopeApi) {
        return DashScopeChatModel.builder()
                .dashScopeApi(dashScopeApi)
                .defaultOptions(DashScopeChatOptions.builder()
                        .model("qwen-plus")
                        .temperature(0.7)
                        .maxToken(2000)
                        .topP(0.9)
                        .build())
                .build();
    }

    @Bean
    public ChatClient dashScopeChatClient(@Qualifier("dashScopeChatModel") DashScopeChatModel dashScopeChatModel) {
        return ChatClient.builder(dashScopeChatModel).build();
    }
}
```

测试接口：

```java
private final ChatClient chatClient;

public ChatController(ChatClient chatClient) {
    this.chatClient = chatClient;
}
```
