## 前言

**Skills**，是一套可复用、可组合的指令与资料集合，是 AI 的“员工手册”或“SOP（标准作业程序），用来实现 AI 在特定垂直任务中“会做、做对、做得标准”的目标

### Skills 核心特征

- **按需加载，渐进式披露**：AI 不会一次性把所有技能都塞进脑子里。它启动时只看技能的“目录索引”（名称和描述），当判断任务需要时，才加载完整的执行指令，从而节省 Token 并提高效率
- **持久化与可复用**：与一次性的临时提示词不同，Skills 是持久化的工程资产。写一次，就可以在多个会话、多个项目中反复使用，甚至分享给团队
- **可组合性**：多个 Skills 可以协同工作，AI 会根据任务需要动态调度和组合它们，形成复杂的工作流

### Skills 物理结构

- **`SKILL.md`（必选）**：主文件，包含元数据（如名称、触发条件）和详细的执行指令（告诉 AI 遇到什么任务该怎么做）
- **`references/`（可选）**：深度参考资料、决策表或领域知识文档，供 AI 在执行时查阅
- **`tools/` 或 `scripts/`（可选）**：辅助执行的代码片段或脚本，让 AI 能够完成具体的自动化操作
- **`assets/`（可选）**：输出模板、示意图等静态资源

#### SKILL.md

包含以下部分：

**一、元数据**：文件最顶部，由 `---` 包裹，AI 用来识别和索引技能的依据

**必填字段：**

- **`name`（）**：技能名称，技能的唯一标识。仅允许使用小写字母、数字和连字符（-），且必须与技能所在的父文件夹名称完全一致
- **`description`**：技能描述，决定 AI 何时触发该技能的核心依据。需要清晰说明技能的功能、适用场景，并尽量包含高频的触发关键词

**可选字段：**

- **`license`**：许可证名称或引用
- **`compatibility`**：环境兼容性说明，例如运行该技能所需的系统环境或依赖包
- **`metadata`**：自定义的键值对，常用于记录作者、版本号等扩展信息
- **`allowed-tools`**：预批准的工具列表

**二、Markdown 指令正文区**：紧跟在元数据下方，是给 AI 的具体执行指引。为了保证 AI 的上下文不被过度消耗，正文需要控制在 500 行或 5000 tokens 以内

一份高质量的正文通常包含以下核心模块：

- **功能与适用场景**：明确界定该技能“能做什么”以及“不能做什么”，并说明正向/负向触发的情形
- **执行步骤**：将任务拆解为线性、无歧义的分步操作说明
- **输入与输出示例**：提供真实的指令案例和标准化的结果格式，防止 AI 的工作流发散
- **注意事项与兜底方案**：包含环境依赖、安全红线、常见边界情况（Edge cases）的处理以及错误处理建议

## 步骤示例

### SkillRegistry

负责**加载、管理所有技能**，Spring AI Alibaba 提供两种常用实现：

- `ClasspathSkillRegistry`：从项目类路径（resources）加载技能
- `FileSystemSkillRegistry`：从本地文件系统加载技能

```java
SkillRegistry registry = ClasspathSkillRegistry.builder()
        .classpathPath("skills")
        .build();
```

### SkillsAgentHook

技能钩子，连接**智能体**与**技能系统**的桥梁，负责注入技能上下文、提供工具调用能力

```java
SkillsAgentHook hook = SkillsAgentHook.builder()
        .skillRegistry(registry)
        .build();
```

### 注册技能钩子

```java
ReactAgent agent = ReactAgent.builder()
        .name("skills-agent")
        .model(chatModel)
        .hooks(List.of(hook))          // 绑定技能钩子
        .build();
```

## Skill 示例

### 计算 BMI Skill

````md
---
name: calculate_bmi
description: 根据身高体重计算BMI身体质量指数，评估健康状态
---

# BMI 计算技能

## 功能说明

你是 BMI 计算专家。当用户询问关于体重指数、身体质量指数或健康评估时，使用此技能。

## 使用方法

1. **获取输入参数**

   - `weight_kg`: 体重（千克）
   - `height_m`: 身高（米）

2. **执行计算**

   - BMI = 体重(kg) / 身高(m)²

3. **健康评估标准**
   | BMI 范围 | 健康状态 |
   |----------|----------|
   | < 18.5 | 偏瘦 |
   | 18.5 ~ 24 | 正常 |
   | 24 ~ 28 | 偏胖 |
   | >= 28 | 肥胖 |

## 计算脚本

使用 Python 脚本进行计算：

```python
def calculate_bmi(weight_kg: float, height_m: float) -> dict:
    if height_m <= 0 or weight_kg <= 0:
        return {"error": "身高和体重必须大于0"}

    bmi = weight_kg / (height_m ** 2)
    bmi = round(bmi, 2)

    if bmi < 18.5:
        status = "偏瘦"
    elif bmi < 24:
        status = "正常"
    elif bmi < 28:
        status = "偏胖"
    else:
        status = "肥胖"

    return {
        "bmi": bmi,
        "status": status,
        "message": f"您的BMI为 {bmi}，属于【{status}】范围。"
    }
```

## 脚本位置

计算脚本位于: `scripts/calculate_bmi.py`

## 输出格式

```json
{
  "bmi": 22.86,
  "status": "正常",
  "message": "您的BMI为 22.86，属于【正常】范围。"
}
```
````

### 配置类

```java
@Configuration
public class SkillChatModelConfig {

    @Value("${spring.ai.dashscope.api-key:}")
    private String apiKey;

    @Value("${spring.ai.dashscope.chat.model:qwen-plus}")
    private String model;

    @Value("${spring.ai.dashscope.chat.temperature:0.7}")
    private Double temperature;

    @Value("${agent.react.name}")
    private String agentName;

    @Value("${agent.react.enable}")
    private boolean enableLogging;

    @Value("${agent.react.classpath-path}")
    private String classpathPath;

    @Bean
    public ChatModel chatModel() {
        return DashScopeChatModel.builder()
                .dashScopeApi(DashScopeApi.builder()
                        .apiKey(apiKey)
                        .build())
                .defaultOptions(DashScopeChatOptions.builder()
                        .model(model)
                        .temperature(temperature)
                        .build())
                .build();
    }

    /**
     * 技能注册中心，加载、管理所有技能
     *
     * @return 从项目类路径（resources）加载技能
     */
    @Bean
    public ClasspathSkillRegistry skillRegistry() {
        return ClasspathSkillRegistry.builder()
                .classpathPath(classpathPath)
                .build();
    }

    /**
     * 技能钩子，注入技能上下文
     *
     * @param skillRegistry 技能注册中心
     * @return 技能钩子
     */
    @Bean
    public SkillsAgentHook skillsAgentHook(ClasspathSkillRegistry skillRegistry) {
        return SkillsAgentHook.builder()
                .skillRegistry(skillRegistry)
                .build();
    }

    /**
     * 构造智能体
     *
     * @param chatModel 语言模型
     * @param skillsAgentHook 技能钩子
     * @return 智能体
     */
    @Bean
    public ReactAgent reactAgent(ChatModel chatModel, SkillsAgentHook skillsAgentHook) {
        return ReactAgent.builder()
                .name(agentName)
                .model(chatModel)
                .hooks(List.of(skillsAgentHook))
                .enableLogging(enableLogging)
                .build();
    }
}
```

### Service

```java
@Service
public class SkillAgentService {

    private static final Logger logger = LoggerFactory.getLogger(SkillAgentService.class);

    private final ReactAgent agent;

    public SkillAgentService(ReactAgent agent) {
        this.agent = agent;
    }

    public String chat(String question) {
        logger.info("收到问题: {}", question);
        try {
            AssistantMessage call = agent.call(question);
            String text = call.getText();
            logger.info("Agent 回答: {}", text);
            return text;
        } catch (Exception e) {
            logger.error("Agent 执行失败: {}", e.getMessage(), e);
            return "处理失败: " + e.getMessage();
        }
    }
}
```
