## 核心概念

**人工介入 (HITL)** 允许我们在 Agent 执行敏感操作（如写文件、执行 SQL）前暂停执行，等待人工决策

- **机制**：通过 `HumanInTheLoopHook` 检查工具调用，若匹配策略则触发中断（Interrupt）

- **状态保存**：依赖 **检查点** 机制（如 `MemorySaver` 或 Redis/PostgreSQL）保存图状态，确保执行可暂停并安全恢复

- 决策类型

  - **Approve (批准)**：原样执行操作
  - **Edit (编辑)**：修改参数后执行
  - **Reject (拒绝)**：拒绝执行，并向对话中添加解释反馈

## 基础配置与使用

要在 Agent 中启用 HITL，需配置 Hook 并关联检查点保存器

**配置步骤：**

1. **配置检查点**：生产环境建议使用持久化实现（Redis/PostgreSQL），测试可用 `MemorySaver`。
2. **创建 Hook**：定义哪些工具需要审批（`approvalOn`）。
3. **构建 Agent**：将 Hook 和 Saver 注入 `ReactAgent`。

**代码示例：**

```java
// 1. 配置检查点
MemorySaver memorySaver = new MemorySaver();

// 2. 创建 HITL Hook
HumanInTheLoopHook hitlHook = HumanInTheLoopHook.builder()
    .approvalOn("write_file", ToolConfig.builder().description("文件写入需审批").build())
    .approvalOn("execute_sql", ToolConfig.builder().description("SQL执行需审批").build())
    .build();

// 3. 创建 Agent
ReactAgent agent = ReactAgent.builder()
    .name("approval_agent")
    .model(chatModel)
    .tools(writeFileTool, executeSqlTool)
    .hooks(List.of(hitlHook))
    .saver(memorySaver) // 必须配置
    .build();
```

## 中断处理流程

当 Agent 运行时，流程如下：

1. **触发中断**：Agent 生成响应，Hook 检测到需审批的工具调用，返回 `InterruptionMetadata` 并暂停。
2. **人工审查**：系统捕获 `InterruptionMetadata`，展示工具名称、参数和描述供审查。
3. **恢复执行**：根据人工决策（批准/编辑/拒绝）构建反馈，使用相同的 `threadId` 调用 Agent 恢复运行。

**处理中断逻辑：**

```java
// 检查中断
if (result.isPresent() && result.get() instanceof InterruptionMetadata interruption) {
    // 获取待审批信息
    List<InterruptionMetadata.ToolFeedback> feedbacks = interruption.toolFeedbacks();

    // 构建决策 (例如：批准所有)
    InterruptionMetadata approval = HITLHelper.approveAll(interruption);

    // 恢复执行
    RunnableConfig resumeConfig = RunnableConfig.builder()
        .threadId(threadId)
        .addHumanFeedback(approval) // 注入决策
        .build();
    agent.invokeAndGetOutput("", resumeConfig);
}
```

## 在工作流中嵌套使用

在复杂的 `StateGraph` 中嵌套 `ReactAgent` 时，HITL 的配置略有不同。

表格

| 特性           | 单独 Agent                   | 工作流中的 Agent                     |
| :------------- | :--------------------------- | :----------------------------------- |
| **检查点配置** | Agent 级别配置               | 需在 `CompileConfig` 中注册          |
| **中断检查**   | `agent.invokeAndGetOutput()` | `compiledGraph.invokeAndGetOutput()` |
| **恢复执行**   | 直接调用 Agent               | 调用 `CompiledGraph`                 |
| **状态管理**   | Agent 内部状态               | 工作流全局状态                       |

**关键注意事项：**

- **共享 Saver**：工作流和嵌套 Agent 必须使用**同一个**检查点保存器实例。
- **恢复输入**：恢复执行时通常传入空 `Map`，因为状态已从检查点恢复。
- **节点标识**：`InterruptionMetadata.node()` 返回的是工作流中 Agent 节点的名称。

## 实用工具方法

文档提供了一组静态工具方法，用于简化决策构建：

- `HITLHelper.approveAll(metadata)`：批准所有待处理工具。
- `HITLHelper.rejectAll(metadata, reason)`：拒绝所有工具，并附带拒绝理由。
- `HITLHelper.editTool(metadata, toolName, newArgs)`：针对特定工具修改参数并批准，其余默认批准。
