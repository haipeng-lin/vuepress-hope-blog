## 核心概念

- **StateGraph（状态图）**：工作流的蓝图设计器。负责定义整个工作流的结构，包含节点注册、边的关系以及图的执行引擎。
- **Node（节点）**：工作流的基本执行单元。每个节点专注于单一职责，接收全局状态作为输入，处理后返回更新后的状态。支持 LLM 节点、工具节点、业务逻辑节点、分类节点等。
- **Edge（边）**：定义节点之间的连接关系和流转条件。支持固定顺序跳转、基于状态的动态条件分支以及多节点并行执行。
- **OverAllState（全局状态）**：贯穿整个图执行周期的数据中枢（共享内存）。采用键值对存储，支持跨节点传递上下文、中间结果和最终输出。
- **CompiledGraph（编译图）**：StateGraph 编译后的可执行版本。负责实际的节点执行、状态流转和结果输出，优化了执行路径

### 覆盖策略

为了控制节点更新如何应用到全局状态，框架为每个键提供了独立的更新策略：

- **ReplaceStrategy（覆盖策略）**：新值完全替换旧值（默认策略）
- **AppendStrategy（追加策略）**：新值追加到旧值之后，非常适合消息列表、日志等需要保留全部记录的场景
- **MergeStrategy（合并策略）**：将新旧值进行合并

### 边

边定义了逻辑如何路由以及图如何决定停止，边的分类如下

- 普通边（Normal Edges）：直接从一个节点到下一个节点。
- 条件边（Conditional Edges）：调用函数来确定接下来要去哪个节点。
- 入口点（Entry Point）：当用户输入到达时首先调用哪个节点。
- 条件入口点（Conditional Entry Point）：调用函数来确定当用户输入到达时首先调用哪个节点。

## 核心方法

### StateGraph 构建方法

- **`new StateGraph(keyStrategyFactory)`**：初始化状态图，传入状态更新策略工厂。
- **`.addNode(String id, NodeAction action)`**：添加一个处理节点，指定节点 ID 和具体的执行逻辑。
- **`.addEdge(String from, String to)`**：添加一条普通边，定义节点间的固定流转顺序。
- **`.addConditionalEdges(...)`**：添加条件边，根据运行时状态动态决定下一步走向。
- **`.compile()`**：将蓝图编译为可执行的 `CompiledGraph`，此阶段会校验图结构合法性。

### CompiledGraph 执行方法

- **`.invoke(Map<String, Object> inputs)`**：以阻塞方式执行整个工作流，一次性返回最终的全局状态（`OverAllState`）。
- **`.stream(Map<String, Object> inputs)`**：以非阻塞的流式方式执行，每当节点完成即返回 `NodeOutput` 事件，适合前端实时展示进度。

### NodeAction 节点接口

- **`Map<String, Object> apply(OverAllState state)`**：最简同步接口，接收当前全局状态，返回需要更新的键值对 Map。
- **`node_async(...)` / `edge_async(...)`**：静态包装方法，将同步的节点或边逻辑包装为异步执行，提升高并发场景下的吞吐量。

## 举例—无 Agent

### 定义&编译图

```java
@Configuration
public class LightWorkflowConfig {

    // 定义状态更新策略工厂
    private KeyStrategyFactory createKeyStrategyFactory() {
        return () -> {
            Map<String, KeyStrategy> strategies = new HashMap<>();
            strategies.put("user_input", new ReplaceStrategy());      // 覆盖策略
            strategies.put("intent", new ReplaceStrategy());          // 覆盖策略
            strategies.put("device_command", new ReplaceStrategy());  // 覆盖策略
            strategies.put("messages", new AppendStrategy());         // 追加策略（保留对话历史）
            return strategies;
        };
    }

    @Bean
    public CompiledGraph lightControlGraph(ChatClient.Builder chatClientBuilder) throws GraphStateException {
        ChatClient chatClient = chatClientBuilder.build();

        StateGraph graph = new StateGraph(createKeyStrategyFactory())
                // 1. 添加节点 (Nodes)
                .addNode("intent_classifier", node_async(state -> {
                    // 优化 Prompt：让大模型输出严格的分类标识
                    String input = state.value("user_input").orElse("").toString();
                    String prompt = String.format("你是一个水族灯控制路由专家。请判断以下用户指令属于哪种类型，并只返回以下四个单词之一：\n" + "1. preset_mode (设置灯光预设模式，如：开启草缸模式、夜间模式)\n" +
                            "2. basic_control (基础调灯，如：把灯调亮一点、色温调到5000K)\n" +
                            "3. device_linkage (设备联动，如：开启光合作用自动联动、根据水质自动调光)\n" +
                            "4. query_data (查询设备数据，如：现在水温多少、当前亮度是多少)\n\n" +
                            "用户指令：%s", input);

                    String intent = chatClient.prompt(prompt).call().content().trim().toLowerCase();
                    return Map.of("intent", intent);
                }))
                .addNode("preset_mode", node_async(state ->
                        Map.of("device_command", "✅ 已为您切换至指定的灯光预设模式。")
                ))
                .addNode("basic_control", node_async(state ->
                        Map.of("device_command", "💡 已执行基础调光指令。")
                ))
                .addNode("device_linkage", node_async(state ->
                        Map.of("device_command", "🔗 已启动设备联动与自动化任务。")
                ))
                .addNode("query_data", node_async(state ->
                        Map.of("device_command", "📊 正在为您查询并汇总当前设备运行数据...")
                ))
                .addNode("response_generator", node_async(state -> {
                    String command = state.value("device_command").orElse("未识别到有效指令").toString();
                    return Map.of("messages", "系统回复: " + command);
                }))

                // 2. 定义固定流程边 (Edges)
                // 所有业务节点执行完毕后，统一流向回复生成节点
                .addEdge(StateGraph.START, "intent_classifier")
                .addEdge("preset_mode", "response_generator")
                .addEdge("basic_control", "response_generator")
                .addEdge("device_linkage", "response_generator")
                .addEdge("query_data", "response_generator")
                .addEdge("response_generator", StateGraph.END)

                // 3. 定义条件路由边 (Conditional Edge)
                .addConditionalEdges("intent_classifier",
                        edge_async(state ->
                                // 安全获取意图，防止空指针
                                state.value("intent").orElse("unknown").toString()
                        ),
                        // 路由映射表：将大模型返回的意图映射到对应的节点 ID
                        Map.of(
                                "preset_mode", "preset_mode",
                                "basic_control", "basic_control",
                                "device_linkage", "device_linkage",
                                "query_data", "query_data"
                        )
                );

        // 4. 编译图
        return graph.compile();
    }
}
```

### 接口

```java
@RestController
@RequestMapping("/light")
public class LightController {

    private final CompiledGraph lightControlGraph;

    public LightController(CompiledGraph lightControlGraph) {
        this.lightControlGraph = lightControlGraph;
    }

    @GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<String> adjustLight(@RequestParam String query) {
        // 传入初始状态，以流式方式执行图
        return lightControlGraph.stream(Map.of("user_input", query))
                .map(nodeOutput -> nodeOutput.state().value("messages").orElse("处理中...").toString());
    }
}
```
