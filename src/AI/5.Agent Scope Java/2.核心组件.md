### 创建方式

- 字符串 model id

```java
ReActAgent agent =
        ReActAgent.builder()
                .name("assistant")
                .model("dashscope:qwen-plus") // 底层由 ModelRegistry.resolve(modelId) 解析
                .build();
```

模型提供商会读取自己的标准环境变量，例如 `DASHSCOPE_API_KEY`、`OPENAI_API_KEY`、`DEEPSEEK_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY`。

- 

需要自定义 API key、base URL、formatter、transport、timeout、生成参数或其他提供商专属配置时，推荐显式构造模型，再把 `Model` 实例传给 agent：

```java
import io.agentscope.extensions.model.dashscope.DashScopeChatModel;
import io.agentscope.extensions.model.dashscope.formatter.DashScopeChatFormatter;

DashScopeChatModel model =
        DashScopeChatModel.builder()
                .apiKey(System.getenv("DASHSCOPE_API_KEY"))
                .modelName("qwen-plus")
                .stream(true)
                .formatter(new DashScopeChatFormatter())
                .build();

ReActAgent agent =
        ReActAgent.builder()
                .name("assistant")
                .model(model)
                .build();
```

```java
import io.agentscope.core.message.UserMessage;
import io.agentscope.core.model.ChatResponse;
import io.agentscope.extensions.model.dashscope.DashScopeChatModel;
import io.agentscope.core.model.GenerateOptions;
import io.agentscope.extensions.model.dashscope.formatter.DashScopeChatFormatter;
import java.util.List;

DashScopeChatModel model =
        DashScopeChatModel.builder()
                .apiKey(System.getenv("DASHSCOPE_API_KEY"))
                .modelName("qwen-plus")
                .stream(true)
                .formatter(new DashScopeChatFormatter())
                .build();

model.stream(
                List.of(new UserMessage("Count from 1 to 5.")),
                /* tools = */ List.of(),
                GenerateOptions.builder().build())
        .doOnNext(chunk -> System.out.println("Chunk: " + chunk.getContent()))
        .doOnComplete(() -> System.out.println("Stream completed"))
        .blockLast();
```

## 消息

在 AgentScope 中，**消息（Message）**与**事件（Event）**是两种核心数据结构，分别服务于不同的场景：

- **消息 (Msg)**：智能体间通信与持久化的基本单元。代表一个完整的对话轮次，存储在上下文中。
- **事件 (AgentEvent)**：前端交互与流式传输的基本单元。携带增量进度更新（如文本 token、工具调用片段），驱动实时界面和人工介入工作流。

**核心关系**：单次 `call` 调用产生的事件序列，最终会汇聚成恰好一条 `Assistant` 消息。这保证了完整的消息状态始终可以从事件流中还原。

### 消息

`Msg` 类代表对话中的一个轮次，其内容由有序的类型化块（`ContentBlock`）列表组成

**核心字段**

| 方法                  | 类型                 | 说明                                                         |
| :-------------------- | :------------------- | :----------------------------------------------------------- |
| `getId()`             | `String`             | 唯一消息标识符                                               |
| `getRole()`           | `MsgRole`            | 角色：`USER` / `ASSISTANT` / `SYSTEM` / `TOOL`               |
| `getContent()`        | `List<ContentBlock>` | 有序内容块列表（不可变）                                     |
| `getGenerateReason()` | `GenerateReason`     | 退出原因，如 `MODEL_STOP`, `TOOL_SUSPENDED`, `ALL_TOOLS_DENIED` 等 |

**内容块 (ContentBlock)**

消息内容由不同类型的块构成，每种块代表一类独立信息。



| 块类型            | 说明                                          | 允许出现在                    |
| :---------------- | :-------------------------------------------- | :---------------------------- |
| `TextBlock`       | 纯文本内容                                    | `USER`, `ASSISTANT`, `SYSTEM` |
| `DataBlock`       | 二进制数据（图片、音频等），推荐使用          | `USER`, `ASSISTANT`           |
| `ThinkingBlock`   | 模型推理过程（思维链）                        | `ASSISTANT`                   |
| `ToolUseBlock`    | 工具调用，包含 `id`, `name`, `input`, `state` | `ASSISTANT`                   |
| `ToolResultBlock` | 工具执行结果，包含 `state`                    | `ASSISTANT`                   |

> **注意**：角色约束在构造时强制执行。例如，`USER` 消息只能包含文本和多媒体块，`SYSTEM` 消息只能包含 `TextBlock`。

**创建与访问消息**

可以通过便捷构造器或 `builder()` 模式创建消息。

配置示例：

```java
// 1. 便捷构造
UserMessage userText = new UserMessage("user", "这张图片里有什么？");

// 2. 多模态消息 (使用 DataBlock)
UserMessage userMulti = new UserMessage(
        "user",
        TextBlock.builder().text("描述这张图片：").build(),
        DataBlock.builder()
                .source(Base64Source.builder().data("...").mediaType("image/png").build())
                .build());

// 3. 使用 Builder 模式添加元数据
UserMessage msg = UserMessage.builder()
        .name("user")
        .textContent("Hello")
        .build();
```

`Msg` 提供了一系列辅助方法来访问内容：

- `getTextContent()`: 获取所有 `TextBlock` 拼接后的文本。
- `getContentBlocks(Class<T>)`: 按类型过滤获取块列表。
- `getFirstContentBlock(Class<T>)`: 获取首个匹配类型的块。
- `hasContentBlocks(Class<T>)`: 检查是否包含指定类型的块。

### 事件 

事件是消息的流式对应物。智能体在执行过程中会持续产出 `AgentEvent` 对象，表示增量进度。

**事件生命周期**

事件遵循 `start` → `delta` → `end` 的模式，并通过 ID 进行关联：

- **replyId**: 同一次回复中的所有事件共享相同的 `replyId`。
- **blockId / toolCallId**: 用于关联同一个内容块或工具调用的生命周期事件

**从事件流重建消息**

事件流可以按 `replyId` / `blockId` / `toolCallId` 聚合，还原成完整的 `AssistantMessage`。这种设计使得后端可以通过 SSE 将事件流推送给前端，由前端在客户端侧重建消息，即使连接中断也能从检查点恢复。

```java
StringBuilder accumulated = new StringBuilder();

agent.streamEvents(userMsg)
        .doOnNext(event -> {
            if (event instanceof AgentStartEvent start) {
                System.out.println("[start replyId=" + start.getReplyId() + "]");
            } else if (event instanceof TextBlockDeltaEvent delta) {
                // 累积文本增量
                accumulated.append(delta.getDelta());
            } else if (event instanceof ToolCallStartEvent tc) {
                System.out.println("[tool] " + tc.getToolCallName());
            } else if (event instanceof AgentEndEvent end) {
                System.out.println("\n[end] full text:\n" + accumulated);
            }
        })
        .blockLast();
```

## 工具

&emsp;&emsp;在 AgentScope Java 中，工具（Tool）不仅仅是执行逻辑的函数，它还需要感知当前的运行环境。框架通过 `RuntimeContext` 将上下文透传到每一次工具调用中，开发者可以通过**注解式自动注入**或**继承 ToolBase 手动获取**两种方式来使用它

### 注解式自动注入

`@Tool` 常用属性：

| 属性                                      | 类型                                   | 说明                                                       |
| ----------------------------------------- | -------------------------------------- | ---------------------------------------------------------- |
| `name`                                    | `String`                               | tool 名（默认取方法名）                                    |
| `description`                             | `String`                               | 面向 agent 的描述                                          |
| `readOnly`                                | `boolean`                              | 是否只读（默认 `false`）                                   |
| `concurrencySafe`                         | `boolean`                              | 是否可并发调用（默认 `false`）                             |
| `stateInjected`                           | `boolean`                              | 是否在调用时注入 `AgentState` 作为额外参数（默认 `false`） |
| `dangerousFiles` / `dangerousDirectories` | `String[]`                             | 追加自定义危险路径列表                                     |
| `converter`                               | `Class<? extends ToolResultConverter>` | 自定义返回值到 `ToolResultBlock` 的转换器                  |

对于使用 `@Tool` 注解的方法，框架会自动识别参数类型

**判定规则**：

- **模型提供**：带有 `@ToolParam` 注解的参数，或基本类型
- **框架注入**：没有 `@ToolParam` 注解，且不是基本类型、不在 `java.*` / `javax.*` 包下的自定义 POJO。

| 参数类型                 | 注入来源         | 说明                                               |
| :----------------------- | :--------------- | :------------------------------------------------- |
| **ToolEmitter**          | 流式中间产物     | 用于流式输出，无配置时为 no-op                     |
| **Agent**                | 当前 Agent 实例  | 获取当前运行的 Agent 对象                          |
| **AgentState**           | Per-session 状态 | 通过 `RuntimeContext.getAgentState()` 获取         |
| **RuntimeContext**       | Per-call 上下文  | 当前调用的完整上下文对象                           |
| **ToolExecutionContext** | 兼容层           | `runtimeContext.asToolExecutionContext()` (已废弃) |
| **自定义 POJO**          | 用户注册对象     | 通过 `runtimeContext.get(ParamType.class)` 获取    |

代码示例：

- 调用方注册：

  ```java
  RuntimeContext ctx = RuntimeContext.builder()
          .put(UserContext.class, new UserContext("alice", "en"))
          .build();
  agent.call(List.of(new UserMessage("Greet me.")), ctx).block();
  ```

- 方法传入：

  ```java
  public record UserContext(String username, String locale) {}
  
  public class PersonalizedTools {
      @Tool(name = "greet", description = "Greet the user")
      public String greet(
              @ToolParam(name = "greeting") String greeting, // ← 模型提供
              UserContext userCtx) {                          // ← 框架自动注入
          return greeting + ", " + userCtx.username() + "!";
      }
  }
  ```

  



## 权限系统

AgentScope 的权限系统旨在拦截 Agent 的每一次工具调用，并根据预设的策略做出 **允许（ALLOW）**、**拒绝（DENY）** 或 **询问用户（ASK）** 的决策。它通过组合静态配置与动态运行时分析，为 Agent 提供了灵活且安全的行为控制

###  核心决策机制

权限引擎的决策由三个核心组件共同决定

- **Rules (规则)**
  - **最高优先级**。针对特定工具（tool）和调用模式的显式 `ALLOW` / `DENY` / `ASK` 规则
  - 来源
    - **静态配置**：在 `PermissionContextState` 中预先定义
    - **动态建议**：在 `ASK` 提示中，由用户接受系统自动生成的建议规则，用于未来自动处理相同调用
- **Built-in Checks (内置检查)**
  - **不可绕过**。由工具自身在运行时基于真实输入执行的动态安全检查，在 `ToolBase#checkPermissions` 中实现
  - 这些检查不受 `Mode` 或 `Rules` 覆盖，即使是在 `BYPASS` 模式下也依然生效。例如，对 `.ssh/`、`.git/` 等危险路径的保护
- **Mode (模式)**
  - **默认行为**。当调用未命中任何规则时，由全局静态策略决定的默认行为

### 权限模式

| 模式         | 行为                                   | 适用场景            |
| :----------- | :------------------------------------- | :------------------ |
| DEFAULT      | 所有操作都需要显式规则或用户确认       | 最安全，推荐默认值  |
| ACCEPT_EDITS | 自动放行工作目录内的文件操作           | 用户在场的活跃开发  |
| EXPLORE      | 只读模式：放行读操作，拒绝所有写与命令 | 代码探索、规划      |
| BYPASS       | 放行一切（`DENY`/`ASK` 规则仍生效）    | 完全可信的沙箱      |
| DONT_ASK     | 将所有 `ASK` 决策转为 `DENY`           | 无人值守 / 计划任务 |

配置示例：

```java
PermissionContextState permCtx = PermissionContextState.builder()
        .mode(PermissionMode.DEFAULT)
        .build();

ReActAgent agent = ReActAgent.builder()
        .name("my_agent")
        .permissionContext(permCtx)
        .build();
```

### 权限规则

相关方法：addAllowRule、addAskRule、

方法参数如下：

- **toolName**: 规则适用的工具名
- **ruleContent**: 匹配模式，由工具的 `matchRule()` 方法解释。`null` 表示匹配该工具的所有调用
- **behavior**: `ALLOW`, `DENY`, `ASK`, 或 `PASSTHROUGH`
- **source**: 规则来源，如 `"userSettings"`, `"session"`, `"suggested"`

配置示例：

```java
PermissionContextState permCtx = PermissionContextState.builder()
        .mode(PermissionMode.DEFAULT)
        .addAllowRule("safe_read", new PermissionRule("safe_read", null, PermissionBehavior.ALLOW, "userSettings"))
        .addAskRule("dangerous_delete", new PermissionRule("dangerous_delete", null, PermissionBehavior.ASK, "userSettings"))
        .build();
```



## 智能体

`Agent`（接口位于 `io.agentscope.core.agent.Agent`，默认实现是 `ReActAgent`）是 AgentScope 的核心抽象——一个推理-行动循环引擎，将模型、工具、权限系统、人机交互、上下文管理、中间件、状态管理和事件系统整合到一个统一接口中

其主要职责包括：

- 接收输入消息或事件，调用工具完成任务
- 管理上下文（会话历史保存在 `AgentState.getContext()` 中，可通过 `AgentStateStore` 自动持久化）
- 在关键生命周期阶段提供中间件钩子，支持自定义逻辑
- 自动管理并发和串行工具执行

### 核心接口

| 方法                                                  | 描述                                                |
| ----------------------------------------------------- | --------------------------------------------------- |
| `call(List<Msg>)` / `call(List<Msg>, RuntimeContext)` | 运行推理-行动循环，返回 `Mono<Msg>`                 |
| `streamEvents(List<Msg>)` / `streamEvents(Msg)`       | 同 `call`，但以流式方式逐一产出 `AgentEvent` 对象   |
| `observe(Msg)` / `observe(List<Msg>)`                 | 将消息添加到上下文，不触发推理（返回 `Mono<Void>`） |

### 配置智能体

通过 `ReActAgent.builder()...build()` 创建智能体。`.model(...)` 既接受 `ModelRegistry` 解析的字符串 id（最常用、自动读取 env），也接受手动 builder 构造的 `Model` 实例（需要精细控制超时、自定义 endpoint 时用）。

```java
import io.agentscope.core.ReActAgent;
import io.agentscope.core.tool.Toolkit;

ReActAgent agent =
        ReActAgent.builder()
                .name("my_agent")
                .sysPrompt("你是一个有帮助的助手。")
                // 由 ModelRegistry 解析；自动读取 DASHSCOPE_API_KEY
                // 切换其他厂商时改成 "openai:gpt-5.5" / "anthropic:claude-sonnet-4-5"
                // / "gemini:gemini-2.0-flash" / "ollama:llama3" 即可。
                .model("dashscope:qwen-plus")
                .toolkit(new Toolkit())
                .build();
```

```java
@Slf4j
public class AquariumTools {

    @Tool(
            name = "获取鱼缸今日最高温度",
            description = "获取鱼缸今天的最高水温。返回今日最高温度。",

            concurrencySafe = true)
```
