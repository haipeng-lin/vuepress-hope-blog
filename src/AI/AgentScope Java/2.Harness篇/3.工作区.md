## 概述

工作区的本质是：**一个智能体的人格与记忆，不再藏在代码或数据库里，而是一整个用 Markdown 和 JSON 拼起来的文件夹。** "它是谁"写在文件里，"它学到了什么"也写在文件里——改文件就是在改智能体本身。

## 设计理念

### 定义&进化

**定义**

| 要定义的内容             | 文件                                |
| :----------------------- | :---------------------------------- |
| 人格、行为约定、系统指令 | `AGENTS.md`                         |
| 领域知识                 | `knowledge/KNOWLEDGE.md` + 参考文件 |
| 技能（可复用能力包）     | `skills/<skill-name>/SKILL.md`      |
| 子 agent 声明            | `subagents/<agent-id>.md`           |
| 工具白名单 + MCP server  | `tools.json`                        |

**进化**

Agent 跨会话累积学到的一切—— 框架自动写，用户不用管生命周期：

- 长期记忆（`MEMORY.md` + `memory/`）
- 自学习技能（`skills/`）
- 计划文件（`plans/`）
- 工具结果落盘（超大输出存磁盘，上下文只留预览+指针）
- 会话日志（`agents/<id>/sessions/`，永不压缩）

### 生命周期分类

| 类型                           | 谁写           | 谁读                  | 例子                                               |
| :----------------------------- | :------------- | :-------------------- | :------------------------------------------------- |
| **静态资产**（工程师编辑）     | 你/团队        | 框架每轮注入 prompt   | `AGENTS.md`、`knowledge/`、`skills/`、`tools.json` |
| **运行时文件**（每次调用写回） | 框架/agent     | 下次调用还原          | `sessions/`、`tasks/`、`plans/`                    |
| **长期记忆**（跨会话累积）     | agent+后台任务 | 每轮注入+agent 自己查 | `MEMORY.md`、`memory日期.md`                       |

**注意，`AgentState` 不属于工作区！**它保存的是"易失的运行期上下文"（对话缓冲、滚动摘要、各种子上下文），存在**独立子系统 `AgentStateStore`**（默认 `~/.agentscope/state/`，在工作区之外）

### 原生多租户隔离

工作区数据由一个 IsolationScope 自动"分桶"，可用的值如下

| Scope          | 谁共享一个桶         | 场景                    |
| :------------- | :------------------- | :---------------------- |
| `SESSION`      | 每个会话完全隔离     | 一次性沙箱              |
| `USER`（默认） | 同一用户所有会话共享 | 用户多会话共享记忆/技能 |
| `AGENT`        | 该 agent 所有用户    | 共享知识库型 agent      |
| `GLOBAL`       | 全实例一个桶         | 慎用，会争抢            |

注意：`AgentState` 有自己独立的寻址方式——永远按 `(userId, sessionId)` 存，不受 scope 影响

### 工作区类别

同一份目录布局，可以落在三个地方，**代码一行不改，只换后端**：

- 本机磁盘
- 共享 KV 存储（Redis / JDBC / OSS）
- 沙箱容器

## 工作区目录树

```shell
.agentscope/workspace/
├── AGENTS.md          ← 静态：人格+行为    （唯一你真正需要写的）
├── MEMORY.md          ← 长期记忆（策划后的事实）
├── tools.json         ← 静态：工具白名单+MCP（可选）
├── memory/            ← 长期记忆（每天流水账）
├── knowledge/         ← 静态：领域知识
├── skills/            ← 静态：技能包
├── subagents/         ← 静态：子 agent 声明
├── plans/             ← 运行时：计划文件
└── agents/<agentId>/  ← 运行时：每个 agent 自己的根
    ├── sessions/      ← 会话索引 + 永不压缩日志
    └── tasks/         ← 子 agent 后台任务记录
```
